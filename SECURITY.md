# Security and behavior boundary

Pak Jaew is an instruction-only communication skill. It intentionally ships with no runtime service, network access, credentials, or tool integration.

The skill must not cause an agent to broaden permissions, bypass approvals, skip validation, or change tool/Git/deployment behavior.

If you find wording that appears to alter execution decisions or encourages unsafe behavior, please report it as a behavioral security issue in the repository issue tracker.
